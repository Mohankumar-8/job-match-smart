# AI Recruit

Build a modern, professional and responsive UI/UX for my project: “AI Resume Screening System”.

Create a clean dashboard-style frontend for recruiters/HR users.

Main page requirements:

- Header with logo/name “AI Resume Screening System”

- Navigation: Dashboard, Resume Screening, Candidates, Results, Settings

- Hero section with a clear headline: “Screen Resumes Smarter with AI”

- Resume PDF drag-and-drop upload area

- Job Description input/upload area

- Primary CTA button: “Analyze Resume”

- Show supported format: PDF

- After analysis, display:

  - Overall Match Score as a circular percentage

  - Matched Skills

  - Missing Skills

  - Experience Match

  - Education Match

  - AI Recommendation

- Candidate result cards with candidate name, score, skills and recommendation

- Add loading/progress state while AI analysis is running

- Add empty states and error states

- Responsive design for desktop, tablet and mobile

- Use a professional AI/SaaS visual style with cards, subtle shadows, rounded corners and clear typography

- Use accessible contrast, keyboard-friendly controls and intuitive UX

- Add smooth but subtle animations and hover states

- Do not use unnecessary gradients or excessive decorative elements

The design should look like a real production-ready AI recruitment platform, not a basic student demo.
